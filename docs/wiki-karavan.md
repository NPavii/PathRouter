# Караван (PathRouter)

**Караван** — Windows-приложение для построения «цифровых путей»: маршрутов раздачи файлов
«источник → название пути → одно или несколько назначений». Инструмент следит за целостностью
каждой ветви, сам замечает изменения и подсвечивает, что требует синхронизации.

Репозиторий: https://github.com/NPavii/PathRouter (приватный; доступ — у владельца).

## Для чего

Типовой сценарий — раздача проектной документации (ПО, схемы, документация) нескольким
заказчикам: один источник, десять назначений, каждое видно на графе, каждое обновляется
одним кликом. Папка-получатель может одновременно быть источником другого маршрута —
получаются цепочки и кластеры синхронизации, видимые вживую.

## Возможности

- Два вида графа: **слоистый** (источники слева, пути в общих контурах) и **силовой**
  («как в Obsidian»: точки-папки, физика, стрелки направления).
- Фоновое наблюдение за источниками: изменения подсвечиваются за ~5 секунд.
- Пути (группы маршрутов) с переименованием, сворачиванием и общим контуром.
- «Консервация» ветви — отключение проверки и синхронизации одной ветви из десяти.
- Детект конфликта «обе стороны правили» с сохранением обеих версий.
- Контентный хэш — перекопированный файл не считается изменённым.
- Поиск файла по всем путям («где лежат копии этого файла»).
- Тёмная тема, Drag&Drop из проводника, импорт/экспорт базы (SQLite).
- Каждый маршрут отвечает только за свои файлы: чужие файлы в общей папке не трогаются.

## Установка

**Standalone-сборка** — .NET Runtime устанавливать НЕ нужно (входит в поставку).

1. Взять готовую папку `publish\` (~215 МБ) из релиза или собрать:

   ```
   git clone https://github.com/NPavii/PathRouter.git
   cd PathRouter
   powershell -ExecutionPolicy Bypass -File deploy.ps1
   ```

2. Скопировать папку `publish\` в любое место:
   - локально: `C:\Program Files\Караван\`
   - на съёмный/сетевой диск — приложение полностью портабельно.

3. Запустить `Караван.exe`. При первом старте создастся база данных.

### Где лежат данные

База маршрутов и настройки — в профиле пользователя, НЕ рядом с программой:

```
%LocalAppData%\PathRouter\routes.db      — база маршрутов и манифестов (SQLite)
%LocalAppData%\PathRouter\settings.json  — тема оформления
%LocalAppData%\PathRouter\error.log      — журнал ошибок (если что-то упало)
```

Перенос маршрутов на другую машину: кнопка **«Экспорт БД»** в приложении (или ручная
копия `routes.db`), на новой машине — **«Импорт БД…»**.

### Системные требования

- Windows 10 (версия 19041+) или Windows 11, x64.
- ~250 МБ диска (включая встроенный .NET Runtime).
- Права на чтение/запись в отслеживаемые папки.

## Быстрый старт

1. Перетащите папку-источник в зону слева, введите название пути, выберите папку
   назначения → «Положить».
2. Поменяйте файл в источнике — за пару секунд над ветвью загорится бейдж ↻.
3. Клик по бейджу — ветвь приведена к актуальному состоянию источника.

Подробный сценарий и все механики — в README репозитория:
https://github.com/NPavii/PathRouter/blob/main/README.md

## Сборка из исходников

Требуется .NET 8 SDK. Сборка только через solution-файл (особенность XAML-компилятора
Windows App SDK — проектная сборка ломает XBF):

```
dotnet restore PathRouter.sln
dotnet build PathRouter.sln -c Release
dotnet run --project src/PathRouter.SmokeTest   # smoke-тест (70+ проверок)
```
